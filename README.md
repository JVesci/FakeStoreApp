# Fake Store App

This is a simple React app that allows users to view, add, edit, and delete products. The app uses the FakeStoreAPI to fetch and manage product data.

## Features
- View Product List: Displays a list of products with the option to view detailed information.
- View Product Details: Shows detailed information for a single product.
- Add Product: Allows users to add a new product to the system.
- Edit Product: Enables users to update existing product details.
- Delete Product: Allows users to delete a product with a confirmation modal.

## Technologies Used
- React
- React Router
- React Bootstrap
- Axios (for API requests)
